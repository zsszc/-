# Spec 023：跨境物流端到端验收集

## 状态

已批准，进入实现阶段。

## 目标

用一组可重复运行的 API 验收测试证明物流 Agent 的关键业务链路可用，并明确身份校验、业务判断和人工接管边界。

## 范围

- 覆盖查件、SLA、报价、禁限寄、异常识别和工单草稿六类能力。
- 覆盖至少一个未授权运单场景和一个参数校验场景。
- 测试只使用本地演示数据，不依赖外部模型、Milvus 或真实承运商接口。
- 不替代已有回归评测数据，作为 API 层端到端冒烟集补充。

## 验收标准

- 六类业务链路均有成功断言。
- 未授权运单返回 404，非法报价参数返回 422。
- 测试可在本地无外部服务状态下稳定运行。
- Spec 回填实现记录，提交并推送代码。

## 实现记录

- 已新增 API 层端到端冒烟集，覆盖查件、SLA、报价、禁限寄、异常识别、工单草稿及边界校验。
- 相关业务测试 15 项通过，`scripts/verify_logistics_release.py` 验收通过（6 份知识材料、30 条回归样例、17 个物流主题）。
