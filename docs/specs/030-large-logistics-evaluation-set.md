# Spec 030：大规模跨境物流训练与综合评估集

## 状态

已批准，进入实现阶段。

## 目标

将分类训练数据扩展到约 300 条，并构建约 300 条按任务类型分层的 Agent 综合评估集，覆盖实际面试项目中最能体现 RAG 与 Agent 能力的场景。

## 数据分层

- 分类训练集：300 条，17 个物流主题，另有独立验证集和分类测试集。
- 政策流程类：100 条，验证单知识文档检索、引用和流程回答。
- 跨文档推理类：70 条，要求组合费用、税费、清关、SLA 或理赔等多个知识来源。
- 工具调用类：60 条，验证查件、报价、禁限寄、异常识别、SLA 和工单工具选择。
- 库外拒答类：50 条，要求明确拒答，不编造实时状态、税率或承运商内部规则。
- 边界澄清类：20 条，验证缺少运单号、重量、目的地或申报价值时先追问。

## 验收标准

- 分类训练集恰好 300 条，17 个主题全部覆盖，文本无重复。
- Agent 综合评估集恰好 300 条，五类数量符合规划，文本无重复。
- 每条评估样例包含类别、期望路由/工具、是否拒答和评测说明字段。
- 数据生成过程可复现，不包含真实个人信息或密钥。
- 当前环境只做数据和质量验收；正式微调依赖单独准备，不伪造训练指标。

## 实现记录

- 已将分类训练集扩展为 300 条，保留 17 个主题覆盖和独立验证/测试集。
- 已生成 300 条 Agent 综合评估集：政策流程 100、跨文档 70、工具调用 60、库外拒答 50、边界澄清 20；其中 50 条要求拒答、250 条要求引用证据。
- 已通过数量、类别、字段、主题合法性和问题去重检查。
