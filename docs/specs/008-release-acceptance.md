# Spec 008：跨境物流项目交付验收

## 状态

已批准，进入实现阶段。

## 目标

提供一条可重复执行的交付前检查命令，确认项目代码、物流资料、回归数据和关键工具均已就绪。

## 验收内容

- 检查 `.env` 不在 Git 跟踪列表中。
- 检查 6 份物流知识库材料存在。
- 检查回归评测集至少 12 条且 JSONL 可解析。
- 检查物流工具和 17 类物流主题已注册。
- 可选地通过 `--live` 检查本地 HTTP 服务三个关键接口。

## 约束

- 默认检查不调用大模型、不产生上游费用。
- `--live` 只访问本机 `127.0.0.1:8000`。
- 检查失败必须返回非零退出码并说明原因。

## 验收标准

- 默认检查成功。
- 本地服务运行时 `--live` 检查成功。
- README 写明交付验收和演示步骤。
- Spec 回填结果并完成提交推送。

## 实现记录

- 已实现 `scripts/verify_logistics_release.py`，默认离线检查和 `--live` 本地接口检查均通过。
- README 已补充演示流程与交付验收命令。
