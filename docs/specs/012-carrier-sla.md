# Spec 012：承运商状态与 SLA 评估

## 状态

已批准，进入实现阶段。

## 目标

让运单查询结果具备可解释的时效评估，演示“状态码 → SLA 判断 → 下一步动作”的运营 Agent 流程。

## 接口

`POST /api/logistics/sla-assessment`

请求字段：`tracking_no`、`user_id`，沿用运单归属校验。

响应字段：运单状态、承运商、标准时效工作日、当前 SLA 状态、建议动作和 `scope=local-demo`。

## 规则

- 复用 `query_shipment` 获取运单快照。
- 演示规则按状态映射 SLA：运输中/清关中为观察，派送中为临近完成，已签收为完成，已揽收为待发运。
- 未知或非本人运单返回 404。
- 不承诺真实到达时间，不接入真实承运商系统。

## 验收标准

- 演示运单返回完整 SLA 字段。
- 不同状态可映射到稳定的 SLA 状态。
- 非本人运单返回 404，缺字段返回 422。
- 看板展示该能力，测试和静态检查通过，Spec 回填实现记录。
