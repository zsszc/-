# Spec 034：物流 Agent 综合评测入口

## 状态

已批准，进入实现阶段。

## 目标

为 300 条物流 Agent 评估集提供可复现的评测入口，覆盖离线数据验收和可选在线调用 `/api/agent` 的行为统计，帮助面试展示 Agent 的工具选择、库外拒答、边界澄清与知识证据表现。

## 范围

- 离线校验评估集总量、分类分布、字段完整性和唯一性。
- 在线模式按样本独立调用 Agent，记录答案、工具调用、工具结果、建议动作和中断信息。
- 按评估类别计算可解释的 pass rate，不把“调用成功”误报成“答案事实正确”。
- 在线评测默认需要显式传入 `--live`，并支持 `--limit` 控制调用数量。

## 评测规则

- `tool_operation`：实际工具调用与期望工具（含别名）有交集。
- `out_of_scope`：没有工具调用，且回答包含拒答/不确定性表达或建议转人工。
- `boundary_clarification`：回答提出补充信息要求，或返回业务中断，并且没有声称不存在的工具结果。
- `policy_process` / `cross_document`：回答非空；要求证据时，回答或工具结果中出现知识依据/引用信号。

规则用于行为回归和面试演示，不能替代人工判断答案事实准确性。

## 验收标准

- 离线模式能够确认当前评估集为 300 条，分类分布为 100/70/60/50/20。
- 在线模式能够保存逐条结果和分类汇总，服务不可用时给出清晰错误而不泄露配置。
- 至少有纯函数测试覆盖工具别名、库外拒答和边界澄清判定。
- 文档提供离线命令及小规模在线抽测命令。
