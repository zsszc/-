# Spec 019：品牌图标去遗留化

## 状态

已批准，进入实现阶段。

## 目标

将聊天页仍沿用的猫形头像和像素风 favicon 替换为“包裹 + 航线”品牌图标，保持现有组件尺寸、颜色体系和交互结构不变。

## 范围

- 替换聊天页 favicon。
- 替换消息头像、欢迎区和输入区复用的 `CAT_SVG`。
- 不修改接口、会话逻辑和组件布局。
- 不引入外部图片或依赖。

## 验收标准

- 页面继续显示“航迹云”品牌文案。
- 页面源代码不再包含旧猫形像素图标特征。
- 头像与 favicon 使用包裹、分栏和航线元素。
- 相关静态检查和回归测试通过，Spec 回填实现记录。

## 实现记录

- 已将 favicon、消息头像、欢迎区和输入区复用图标统一替换为包裹 + 航线 SVG；保留原有组件尺寸和交互结构。
- 未引入外部资源；静态源代码检查和物流回归测试通过。
