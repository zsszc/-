# Spec 005：聊天页运单查询入口

## 状态

已批准，进入实现阶段。

## 目标

将运单查询 API 接入聊天页，为用户提供无需等待 Agent 推理的快速查询入口。

## 交互与约束

- 输入框填写运单号后点击“运单查询”，展示状态、节点、承运商、更新时间和轨迹。
- 未填写运单号或接口返回 404 时显示明确提示。
- 使用当前浏览器生成的 `user_id`，不允许用户输入身份字段。
- 复用 `/api/logistics/shipment-query`，前端不实现归属判断。

## 验收标准

- 页面出现“运单查询”入口。
- 演示运单可展示结构化结果。
- 空输入和未知运单有页面提示。
- 相关测试、静态检查通过，Spec 回填实现记录。

## 实现记录

- 已在 `app/static/index.html` 增加“运单查询”入口，复用 `/api/logistics/shipment-query` 和浏览器会话身份。
- 已覆盖空输入提示，并完成页面静态入口验收；后端运单 API 测试通过。
