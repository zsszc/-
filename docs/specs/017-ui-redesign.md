# Spec 017：航迹云聊天页视觉重构

## 状态

已批准，进入实现阶段。

## 目标

在不改变现有页面信息架构和业务交互的前提下，完成聊天页整体视觉重构，使页面具备独立的跨境物流产品识别度。

## 保留内容

- 会话侧栏、聊天消息区、输入区和工单/退款弹窗结构。
- 运单查询、异常识别、工单草稿、运营概览等现有业务入口。
- 响应式布局、回车发送和现有 API 协议。

## 改造内容

- 采用“深海蓝 + 航线青绿 + 纸张白”的新色彩系统。
- 重做页面背景、容器边框、阴影、按钮、会话卡片、消息气泡和弹窗细节。
- 调整标题、状态徽章、欢迎区、输入区和业务按钮的视觉层级。
- 将旧像素猫头像替换为 CSS/SVG 航线包裹图标，避免依赖外部图片资源。
- 细化桌面端与移动端间距、圆角和布局断点。

## 约束

- 不引入新的前端框架或外部资源。
- 不改动后端业务逻辑和接口协议。
- 不改变用户输入、聊天记录和工单确认行为。

## 验收标准

- 首页出现新的“航迹云”视觉风格和物流业务层级。
- 页面不出现旧项目品牌和旧客服角色文案。
- 现有业务按钮仍可定位，移动端可用。
- 静态页面检查、相关回归测试和浏览器页面验收通过。
- Spec 回填实现记录并提交推送。
