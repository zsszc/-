# Spec 040：跨境物流传统检索指标

## 背景

当前 `/rag-eval` 展示的是端到端 Agent 行为通过率，能够检查工具、拒答和澄清，但不能回答向量检索本身的 Recall、Precision、MRR 与 NDCG。历史 `ch04` 报告属于旧电商语料，不能作为当前物流版本指标。

## 目标

1. 建立与 `data/kb/*.md` 当前 19 个知识小节对应的物流检索评测集。
2. 同时覆盖单证据问题和需要多个知识小节的跨文档问题。
3. 对 vector、BM25、hybrid、hybrid + rerank 四种策略计算标准 Top-K 指标。
4. `/rag-eval` 同时展示检索层指标和最近一次端到端行为抽测，明确区分两个口径。

## 指标定义

- Hit Rate@K：前 K 条是否至少命中一个相关知识小节。
- Precision@K：前 K 条中首次命中的相关小节数除以 K。
- Recall@K：前 K 条命中的相关小节数除以该问题全部标注相关小节数。
- MRR@5：第一个相关小节名次的倒数，前 5 条未命中记 0。
- NDCG@5：按二元相关性计算 DCG，并用理想排序归一化；重复命中同一小节不重复得分。

## 数据与实现约束

- 评测集独立保存，不从查询文本动态猜测答案标签。
- ground truth 使用知识块 `section_path`，与检索返回字段直接比对。
- 多证据问题的每个相关小节分别计入 Recall 与 NDCG。
- 报告由脚本一次性生成，API 和页面只读取产物，避免前后端各算一套。
- API 密钥、原始上游响应和环境变量不得写入报告。

## 验收标准

- 评测集为 30 条，其中 19 条单证据题、11 条多证据题，覆盖全部 19 个知识小节。
- 四种策略都产出 Hit Rate@1、Precision@1/3/5、Recall@1/3/5、MRR@5、NDCG@5。
- 指标计算有纯函数单元测试。
- `/rag-eval` 能展示当前物流指标、样本量、生成时间和端到端行为抽测，不再读取旧电商报告。

## 实现记录

- 已建立 30 条物流检索评测集：19 条单证据题、11 条跨文档题，覆盖当前全部 19 个知识小节。
- 已实现四策略统一评测脚本和 Hit Rate@K、Precision@K、Recall@K、MRR@5、NDCG@5。
- 已完成真实评测，四种策略均为 0 调用错误。当前线上 `hybrid_rerank` 的 Recall@5 为 96.11%、MRR@5 为 94.44%、NDCG@5 为 93.55%。
- 本轮纯向量策略表现最好：Recall@5 98.89%、MRR@5 98.33%、NDCG@5 97.30%；这说明当前重排模型对部分跨文档物流题存在降序问题，页面如实展示，不把生产策略标成最优策略。
