# Spec 015：聊天页工单草稿面板

## 状态

已批准，进入实现阶段。

## 目标

将工单草稿 API 接入聊天页，形成“异常描述 → 分类预检 → 草稿预览 → 人工确认”的前端闭环。

## 交互与约束

- 输入框填写异常描述，可选带上运单号，点击“生成工单草稿”。
- 页面展示工单标题、分类、严重级别、所需材料和人工确认状态。
- 空输入、接口错误显示页面内提示；不自动提交工单，不清空用户输入。
- 复用 `/api/logistics/ticket-draft`，不新增依赖、不修改聊天协议。

## 验收标准

- 页面出现“生成工单草稿”入口。
- 清关异常描述能展示草稿内容。
- 空输入有明确提示，相关回归测试通过。

## 实现记录

- 已在聊天页增加“生成工单草稿”入口，复用工单草稿 API 展示分类、级别、材料和人工确认状态。
- 已覆盖空输入提示，后端草稿接口及相关回归测试通过。
