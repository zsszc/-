# Spec 010：跨境物流运营风格 UI 改造

## 状态

已批准，进入实现阶段。

## 目标

将聊天页从通用客服视觉改为“跨境物流运营助手”视觉，强化运单、清关和异常处理的产品定位。

## 范围与约束

- 统一页面标题、助手名称、欢迎语、输入提示和底部说明。
- 使用蓝色/青绿色物流主题色，保留现有响应式布局和像素风格。
- 为运单查询、异常识别两个业务入口提供明显视觉层级。
- 不引入图片资源或前端框架，不修改接口协议。

## 验收标准

- 页面不再出现“喵喵优选”“商品”“小喵”等原项目业务文案。
- 页面出现“航迹云”“运小助”“跨境物流”“运单查询”“异常识别”。
- 静态页面可正常返回，相关测试通过，Spec 回填实现记录。

## 实现记录

- 已完成聊天页品牌、色彩、输入提示、快捷入口和工单弹窗文案改造。
- 页面静态检查确认包含“航迹云”“运小助”“跨境物流”等业务词，视觉仍保持响应式和像素风格。
