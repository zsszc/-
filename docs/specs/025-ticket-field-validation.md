# Spec 025：物流工单字段校验

## 状态

已批准，进入实现阶段。

## 目标

让异常工单草稿明确展示已填写字段、缺失字段和提交前所需材料，减少人工接管后的补充沟通。

## 范围

- 为工单草稿增加联系人、联系电话和证据材料字段。
- 根据异常类别生成结构化 `field_validation`，包含必填字段、缺失字段和是否完整。
- 草稿允许不完整，但必须明确 `requires_confirmation` 和缺失项。
- 校验手机号和证据材料数量等输入边界，不保存真实工单数据。

## 验收标准

- 清关、破损、丢失等异常能返回不同的必填字段建议。
- 缺少运单号或证据时返回 `complete=false` 和 `missing_fields`。
- 完整请求返回 `complete=true`。
- 非法手机号或过多证据材料返回 422；原有工单调用兼容。
- 相关测试通过，Spec 回填实现记录。

## 实现记录

- 已增加联系人、电话和证据材料字段，并按异常类别返回必填字段、缺失字段和完整性结果；不完整草稿仍可保存并等待确认。
- 已增加手机号与证据数量边界校验；工单草稿和端到端测试共 7 项通过。
