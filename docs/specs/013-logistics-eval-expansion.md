# Spec 013：物流评测集扩充

## 状态

已批准，进入实现阶段。

## 目标

将最小物流回归集从 12 条扩充到至少 30 条，覆盖主要主题、意图和工具能力，为后续评测与微调准备稳定数据基础。

## 数据要求

- 每条继续遵循 Spec 007 的 JSONL 契约。
- 至少覆盖 12 个物流主题。
- 每种 `expected_capability` 至少出现 3 次。
- 使用虚构运单号，不包含真实个人信息。
- query 保持用户真实口语，不写成规则说明书。

## 范围约束

- 不在本轮启动模型训练。
- 不修改原始购买项目数据集。
- 不将 API 密钥、真实订单或真实收件信息写入数据。

## 验收标准

- 样例数量不少于 30 条。
- ID 唯一、字段合法、主题覆盖不少于 12 类。
- 五类能力均至少 3 条。
- 自动化数据契约测试通过，Spec 回填实现记录。

## 实现记录

- 已将物流评测集扩充至 30 条，覆盖 16 个主题和 5 类能力。
- 已增强数据契约测试，校验样例数量、主题覆盖和能力分布；未启动模型训练。
