# Spec 002：聊天页异常识别入口

## 状态

已完成。

## 目标

让用户无需等待完整 Agent 回复，就能在聊天页将物流异常描述转换为结构化结果，辅助判断下一步需要准备的材料。

## 范围与约束

- 在聊天输入区增加“异常识别”按钮和结果区域。
- 调用 `POST /api/logistics/exception-classify`，不复制分类规则。
- 不自动创建工单、不修改运单、不上传用户输入到第三方模型。
- 空输入和接口错误必须给出页面内提示。

## 验收标准

- 输入清关/破损等描述后可显示类别、严重级别和所需材料。
- 空输入显示明确提示。
- 后端接口测试、工具测试通过。
- 页面包含新入口且 Git 中不包含密钥。

## 实现记录

- 已在 `app/static/index.html` 增加“异常识别”入口和结果展示区。
- 前端调用后端结构化接口，不直接实现业务分类逻辑。
- 后端与工具测试已通过，页面静态入口已检查。
