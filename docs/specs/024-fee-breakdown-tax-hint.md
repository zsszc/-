# Spec 024：费用拆解与税费提示

## 状态

已批准，进入实现阶段。

## 目标

让报价结果可解释，区分运输费用组成与目的国税费估算，帮助客服说明价格边界。

## 范围

- 保留 `estimated_fee_cny` 旧字段。
- 增加基础运费、燃油附加费、偏远地区费和运输费用合计。
- 增加可选申报价值；填写后按目的地规则给出关税和 VAT 粗略估算。
- 未填写申报价值时，税费返回 0 并明确提示不是免税承诺。
- 继续使用本地规则，不接入真实海关税率或承运商报价接口。

## 验收标准

- 原有报价结果和接口校验保持兼容。
- 报价结果包含 `fee_breakdown` 和 `tax_estimate`。
- 有申报价值时税费可解释，无申报价值时有明确提示。
- 相关工具/API 测试通过，Spec 回填实现记录。

## 实现记录

- 已保留原有基础运费字段，新增基础运费、燃油附加费、偏远地区费、运输合计和申报价值税费估算。
- 未填写申报价值时返回 0 税费并给出非免税提示；编译检查、报价 API、物流工具和端到端测试共 12 项通过。
