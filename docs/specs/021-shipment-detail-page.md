# Spec 021：运单详情页

## 状态

已批准，进入实现阶段。

## 目标

为客服和运营人员提供可读的运单详情页，将结构化轨迹、线路、SLA 和异常信息集中展示。

## 范围

- 新增 `/shipment-detail` 页面和运单查询表单。
- 页面通过 `/api/logistics/shipment-query` 查询，继续执行用户身份校验。
- 展示运单号、承运商、线路、服务等级、当前状态、预计送达、SLA 截止时间和异常码。
- 使用原生 HTML/CSS/JavaScript，不引入外部资源；兼容移动端。

## 验收标准

- 页面能从输入运单号和用户标识加载详情。
- 查询成功时能渲染 5 节点结构化轨迹和当前节点状态。
- 未授权运单显示明确错误，不泄露运单详情。
- 页面包含返回聊天页入口，静态页面路由测试通过。
- Spec 回填实现记录，提交并推送代码。

## 实现记录

- 已新增 `/shipment-detail` 页面，接入现有身份校验查询接口，展示运单摘要、线路、SLA、异常提示和结构化轨迹时间线。
- 已增加静态路由验收；编译检查、静态页面、运单 API 和物流工具共 12 项测试通过。
