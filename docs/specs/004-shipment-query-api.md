# Spec 004：跨境运单查询 API

## 状态

已批准，进入实现阶段。

## 目标

提供可复用的运单查询 HTTP 契约，统一 Agent、前端和运营工具的运单查询入口。

## 接口

`POST /api/logistics/shipment-query`

请求字段：`tracking_no`、`user_id`。运单查询必须同时校验用户身份和运单归属。

成功响应返回运单号、状态、当前节点、承运商、最近更新时间、预计送达时间和轨迹；非本人或不存在的运单返回 404，不泄露运单是否存在的额外信息。

## 范围约束

- 复用 `query_shipment`，不复制归属判断和 mock 数据逻辑。
- 不接入真实承运商，不修改运单，不保存用户输入。
- 不承诺固定到达时间。

## 验收标准

- 演示用户查询演示运单返回 200 和完整字段。
- 空用户、未知运单返回 404。
- 缺少字段或空字段返回 422。
- API 与工具测试通过，Spec 回填实现记录。

## 实现记录

- 已实现 `app/api/shipment.py`，复用 `query_shipment` 并将非本人运单统一隐藏为 404。
- API 测试覆盖成功查询、未知运单和身份校验。
