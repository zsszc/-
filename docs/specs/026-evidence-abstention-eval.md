# Spec 026：证据不足拒答评测

## 状态

已批准，进入实现阶段。

## 目标

把“知识库没有足够证据时拒答”从代码分支变成可重复验收的物流评测集，防止模型凭常识编造时效、税率或承运商政策。

## 范围

- 新增物流库外问题 JSONL，覆盖实时航班、特殊税率、未收录承运商政策等场景。
- 测试空召回时必须进入低置信度拒答路径，并返回人工转接动作。
- 评测数据只验证拒答契约，不调用外部模型或真实服务。

## 验收标准

- 至少 8 条库外问题，均标记 `must_abstain=true` 和拒答原因。
- 空召回场景 `evidence_strong=false`、`fallback_source=\"retrieval_low_conf\"`。
- 拒答回复包含人工转接动作，不生成知识性结论。
- 评测测试通过，Spec 回填实现记录。

## 实现记录

- 已新增 8 条库外物流问题评测集，并用空召回测试验证全部进入 `retrieval_low_conf` 拒答路径；拒答回复提供人工转接动作并记录空召回快照。
- 发布验收脚本已检查拒答数据集完整性；拒答专项测试 2 项通过。
