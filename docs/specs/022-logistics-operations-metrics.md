# Spec 022：物流运营指标看板

## 状态

已批准，进入实现阶段。

## 目标

让管理员看板展示物流业务指标，而不仅是工程资源数量，帮助说明 Agent 在运营场景中的可观测性。

## 范围

- 在 `/api/logistics/overview` 增加演示运单总量、状态分布、异常分布、承运商履约和人工转接率。
- 指标必须由项目内稳定 mock 数据和评测数据计算，不伪造真实生产统计。
- 看板增加物流指标区和承运商/异常分布区，保留现有知识库、工具和 Milvus 状态卡片。

## 验收标准

- API 返回 `operations` 指标，包含状态、承运商和异常维度。
- 指标计算结果与演示运单数据一致，重复请求稳定。
- 看板能渲染新增指标，Milvus 不可用时仍能显示其他数据。
- 相关 API、页面和回归测试通过，Spec 回填实现记录。

## 实现记录

- 已在 `/api/logistics/overview` 增加演示运单总量、状态分布、异常分布、承运商履约和人工转接率。
- 运营看板已增加物流运营与质量监控区域；编译检查、概览 API、静态页面和运单 API 共 7 项测试通过。
