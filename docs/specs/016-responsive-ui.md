# Spec 016：物流聊天页响应式与可访问性优化

## 状态

已批准，进入实现阶段。

## 目标与范围

保证新增的运单查询、异常识别和工单草稿入口在手机窄屏下仍可操作，并为按钮补充明确的无障碍标签。

- 聊天输入区允许业务按钮自动换行。
- 移动端输入框优先占满一行，按钮保持可点击尺寸。
- 为业务按钮和导航链接提供 `aria-label`。
- 不修改接口、颜色主题和桌面端布局。

## 验收标准

- 页面包含响应式 composer 规则。
- 三个业务按钮均有可读文本和 `aria-label`。
- 页面静态资源正常返回，相关回归测试通过。

## 实现记录

- 已增加 composer 自动换行、移动端按钮尺寸和输入框布局，并为导航及三个业务按钮补充 aria-label。
- 静态页面入口检查通过，后端回归测试保持通过。
