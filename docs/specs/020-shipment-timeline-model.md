# Spec 020：运单轨迹与详情模型

## 状态

已批准，进入实现阶段。

## 目标

将跨境运单从简单状态快照扩展为稳定、可复用的结构化轨迹模型，为 Agent 回复、运单详情页和管理员运营指标提供同一份数据源。

## 范围

- 扩展演示运单快照，增加线路、服务等级、SLA 截止时间、异常码和结构化轨迹节点。
- 保留现有 `status`、`current_node`、`carrier`、`trace` 等字段，避免破坏已有调用方。
- 轨迹节点包含时间、地点、状态、节点说明和完成状态。
- 继续使用确定性 mock 数据，不接入真实承运商接口，不存储真实个人信息。

## 验收标准

- 同一运单号每次返回结果完全稳定。
- 两个演示运单均包含结构化 `events`、`route`、`service_level`、`sla_due_at` 和 `exception_code` 字段。
- `events` 至少包含 4 个节点，并能标识当前节点。
- 原有运单查询 API 和工具测试继续通过。
- Spec 回填实现记录，提交并推送代码。

## 实现记录

- 已扩展稳定的演示运单快照，新增线路、服务等级、SLA 截止时间、异常码和 5 节点结构化轨迹；保留原有兼容字段。
- 已补充结构化轨迹回归测试；编译检查、运单工具、运单 API 和 SLA API 共 11 项测试通过。
