# Spec 027：物流分类器训练前后对比

## 状态

已批准，进入实现阶段。

## 目标

用一套不依赖外部模型下载的可复现实验，量化旧领域样例和物流领域样例加入前后的主题分类效果，为后续是否进行 Transformer 微调提供依据。

## 范围

- 将旧电商训练集作为 baseline 样例库。
- 将物流主题示例和物流回归集前 20 条加入 augmented 样例库。
- 在物流回归集后 10 条固定留出集上比较准确率和逐条预测。
- 采用本地字符 n-gram 相似度分类器，结果用于数据质量对比，不冒充 Transformer 微调指标。

## 验收标准

- 生成包含 baseline/augmented 样例数、留出集大小、accuracy 和提升值的 JSON 报告。
- augmented accuracy 不低于 baseline accuracy。
- 报告保留每条留出样例的真实标签和预测标签，便于分析错误。
- 测试和 Spec 回填实现记录。

## 实现记录

- 已新增可复现的字符二元组样例分类对比脚本和报告：旧样例 baseline 准确率 0.10，加入物流术语与 20 条领域样例后为 0.40，提升 0.30。
- 报告包含 10 条独立留出样例的逐条前后预测；该结果明确标注为数据增量对比，不冒充 Transformer 微调指标。
