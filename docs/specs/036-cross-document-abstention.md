# Spec 036：跨文档工具路由与库外拒答优化

## 状态

已批准，进入实现阶段。

## 目标

修复在线评测中跨文档问题和库外问题的行为缺陷：费用与税费组合问题应进入费用工具链；明显超出物流知识库边界的问题应明确拒答，而不是泛化追问运单号。

## 范围

- 将“费用时效”从知识库闸门路由到 Agent 工具链，使 `estimate_shipping_fee` 能处理运费、燃油费、偏远地区费和税费估算。
- 为航班实时状态、承运商内部规则等明确库外关键词增加确定性拒答文案。
- 评测规则把成功工具结果作为可追溯证据，避免工具型跨文档回答因没有 `[1]` 引用格式被误判。
- 不接入分类器主链路，不新增外部 API。

## 验收标准

- 费用时效路由为 `business`，可进入 Agent 工具调用环。
- 明显库外问题不调用工具，回答包含明确无法确认/超出范围表达。
- 评测工具结果能够满足证据判定。
- 现有回归测试和定向测试通过，并完成一次在线抽样复测。

## 实现记录

- 已将“费用时效”路由调整为 `business`，并补充费用与申报价值组合问题的工具选择提示。
- 已为航班实时状态、承运商内部规则等库外问题增加确定性拒答文案。
- 已让评测把成功工具结果作为工具型证据，并新增 3 个定向回归测试。
- 定向在线复测 12 条：跨文档 5/6（83.33%）、库外拒答 6/6（100%），合计 11/12（91.67%）。剩余 1 条是缺少运单号的 SLA 复合问题，属于应澄清参数的边界样本。
