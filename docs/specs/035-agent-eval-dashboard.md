# Spec 035：物流 Agent 评测看板

## 状态

已批准，进入实现阶段。

## 目标

把 300 条物流 Agent 综合评估集及最近一次在线评测结果接入后台，让开发者无需查看终端 JSON 就能确认评测集规模、类别分布和行为指标。

## 范围

- 提供只读 `GET /api/agent-eval/overview`。
- 新增后台评测页，展示数据集就绪情况、在线评测汇总和分类通过率。
- 后台首页新增 Agent 评测卡片。
- 没有在线报告时显示“未评测”，不把缺少报告当成服务故障。

## 约束

- 页面只读产物，不在请求中调用模型、不重跑评测。
- 不返回环境变量、API key 或逐条模型原始响应。
- 保持现有后台导航和视觉系统，不引入前端框架。

## 验收标准

- 300 条数据和五类分布能够通过 API 和页面展示。
- 有在线报告时展示总通过率和五类指标；无报告时给出明确下一步命令。
- 相关 API 单测通过，Spec 回填实现记录并提交推送。

## 实现记录

- 已新增只读 `GET /api/agent-eval/overview`，汇总 300 条评估集和最近在线报告，不触发模型调用。
- 已新增 `/agent-eval` 看板、后台首页 Agent 评测卡片，并修正后台页标题为“航迹云”。
- 待补：在完整 pytest 环境下执行全量回归。
