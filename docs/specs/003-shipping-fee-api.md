# Spec 003：跨境运输费用估算 API

## 状态

已批准，进入实现阶段。

## 目标

为运费估算提供稳定的 HTTP 契约，供聊天 Agent、前端表单和后续线路看板复用同一套计算逻辑。

## 接口

`POST /api/logistics/shipping-fee`

请求字段：`origin`、`destination`、`weight_kg`、`transport_mode`。

运输方式仅允许：`经济`、`标准`、`特快`；重量范围为 `(0, 1000]` kg。

响应必须包含起讫地、重量、运输方式、估算人民币金额和“不代表最终报价”的提示。

## 范围约束

- 接口复用 `estimate_shipping_fee`，不复制计算公式。
- 不接入真实承运商报价，不收集或保存个人信息。
- 不包含目的国税费、偏远地区费等最终报价承诺。

## 验收标准

- 三种运输方式返回不同估算结果。
- 非法运输方式、零重量、超大重量返回 422。
- API 与工具测试通过。
- README 和实现记录同步。
