# Spec 032：单主题物流分类基准

## 状态

已批准，进入实现阶段。

## 目标

将单标签分类评测与跨主题 Agent 评测分离，避免用“运费 + 关税 + 清关”这类复合问题不公平地评价单一主题分类器。

## 范围

- 为 17 个物流主题生成均衡的单主题验证集和测试集。
- 每条分类样例只标注一个主题，句式覆盖咨询、问题描述和客服口语。
- 与 v2 训练集做精确文本去重，保留跨文档问题在 `logistics_agent_eval.jsonl`。
- 训练脚本使用新验证集，评测脚本使用新测试集。

## 验收标准

- 验证集 51 条、测试集 170 条，每个主题分别 3 条和 10 条。
- 所有样例只含一个 canonical 标签，17 类分布均衡。
- 与 v2 训练集无文本重复。
- 生成报告并完成一轮训练评估，记录新旧基准差异。

## 实现记录

- 已生成均衡单主题验证集 51 条、测试集 170 条，每个主题分别 3 条和 10 条；与 v2 训练集无重复。
- 跨主题问题继续保留在 300 条 Agent 综合评估集，不再混入单标签分类测试。
- 新单标签模型在 170 条测试集上达到 micro-F1 0.8471、macro-F1 0.8520。
