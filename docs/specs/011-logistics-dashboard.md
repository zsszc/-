# Spec 011：物流运营概览看板

## 状态

已批准，进入实现阶段。

## 目标

提供一个轻量运营概览页，集中展示当前项目的知识库、评测集、主题分类和工具能力，便于演示 Agent 系统的业务闭环。

## 接口与页面

- `GET /api/logistics/overview` 返回本地项目指标。
- `GET /logistics-dashboard` 展示指标卡片和能力列表。

指标包括：知识材料数量、回归样例数量、物流主题数量、已注册物流工具数量、Milvus 向量数量（无法连接时标记 unavailable）。

## 约束

- 仅展示本地项目状态，不声称是真实业务运营数据。
- 不读取或展示 API 密钥、用户消息和个人信息。
- Milvus 查询失败不导致页面整体失败。

## 验收标准

- 页面可访问并展示指标。
- API 返回指标和工具能力列表。
- Milvus 不可用时仍返回 200 和可读状态。
- 相关测试和静态检查通过，Spec 回填实现记录。

## 实现记录

- 已实现 `GET /api/logistics/overview` 和 `/logistics-dashboard` 页面。
- 页面与接口均标注 local-demo 范围，Milvus 不可用时降级显示；相关接口测试通过。
