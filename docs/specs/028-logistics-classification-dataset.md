# Spec 028：跨境物流分类训练与测试数据集

## 状态

已批准，进入实现阶段。

## 目标

扩展一套面向 AI 应用岗位项目展示的跨境物流主题分类数据，覆盖 17 个物流主题，并保证训练集与测试集可重复生成、标签统一、文本不重叠。

## 范围

- 基于权威物流主题表和已有 30 条回归样例生成领域数据。
- 生成独立的 `logistics_train.jsonl`、`logistics_val.jsonl` 和 `logistics_test.jsonl`，标签只使用 17 个 canonical 主题名。
- 训练集包含主题示例改写和回归样例；测试集使用不同句式，并保留回归样例留出部分。
- 输出数据质量报告，记录样本数、主题覆盖和重复文本检查结果。
- 不混入真实个人信息、API 密钥或真实运单隐私。

## 验收标准

- 17 个主题在训练集和测试集均有样本。
- 训练/验证/测试文本无重复，标签全部属于 `TOPIC_NAMES`。
- 数据可被现有分类训练脚本读取，字段至少包含 `text` 和 `labels`。
- 生成过程可重复，质量检查通过并回填 Spec。

## 实现记录

- 已生成 `logistics_train.jsonl` 300 条、`logistics_val.jsonl` 17 条、`logistics_test.jsonl` 57 条，覆盖 17 个物流主题。
- 已通过标签合法性、主题覆盖、三份数据无重复和字段兼容检查。
