# Spec 031：分类训练数据质量优化

## 状态

已批准，进入实现阶段。

## 目标

解决上一轮验证集与独立测试集指标落差，减少模板化数据对分类器的误导。

## 范围

- 为 17 个物流主题补充更接近客服真实对话的口语样本。
- 增加运单查询/运输时效/异常处理、运输费用/关税税费、清关资料/贸易单证/退运处理等相邻主题样本。
- 生成独立 v2 训练集，不覆盖上一版数据，便于对比训练结果。
- 保持 300 条规模、canonical 标签和字段兼容。

## 验收标准

- v2 训练集恰好 300 条，覆盖 17 个主题。
- 文本去重通过，样本不再全部使用同一个句式模板。
- 至少包含 28 条来自真实物流回归问题的口语化变体。
- 输出主题分布和来源分布报告，Spec 回填实现记录。

## 实现记录

- 已生成 v2 训练集 300 条：272 条自然口语/相邻主题样本，28 条物流回归问题变体，覆盖 17 个主题且文本无重复。
- 已增加训练入口的独立文件参数，可直接使用 v2 训练集而不覆盖 v1 数据。
- v2 进行 2 轮和 6 轮烟测后，独立测试 micro-F1 分别为 0.1344 和 0.1266，确认继续增加轮数不能解决问题；下一步应重构分类测试集和主题边界，避免把跨主题 Agent 问题直接当作单标签分类题。
