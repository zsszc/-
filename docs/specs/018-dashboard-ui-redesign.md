# Spec 018：运营看板视觉统一

## 状态

已批准，进入实现阶段。

## 目标

将运营看板与聊天页统一为“航迹云”产品视觉，强化数据卡片、服务状态和能力列表的层次。

## 范围

- 保留现有看板数据接口和页面信息结构。
- 重做背景、页头、指标卡、能力卡、状态展示和移动端布局。
- 增加“本地演示环境”状态徽章和更新时间提示。
- 不引入外部资源，不修改后端接口协议。

## 验收标准

- 看板使用深海蓝/青绿色主题，与聊天页一致。
- 指标和能力列表清晰可读，移动端不横向溢出。
- 页面保留返回聊天入口并正常请求概览 API。
- 静态检查和相关测试通过，Spec 回填实现记录。

## 实现记录

- 已统一运营看板的深海蓝/青绿色主题，重做页头、指标卡、能力卡、状态徽章和移动端布局。
- 保留返回聊天入口和原有概览 API；静态页面验收通过。
