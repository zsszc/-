# 跨境物流智能运营助手：二开路线

当前版本保留原有 Agent、RAG、MCP、会话记忆、工单和运营观测骨架，先把业务语境切换到跨境物流。

## 已完成：第一阶段垂直链路

- 跨境物流知识库材料：运单 FAQ、清关、运输费用、禁限寄、异常处理、丢损理赔。
- `query_shipment`：按用户身份查询演示运单，避免模型越权查看他人数据。
- `estimate_shipping_fee`：根据起讫地、重量和运输方式给出可解释的估算结果。
- Agent 提示词、检索改写、意图示例和首页交互文案切换到物流场景。

## 已完成：业务深化与可观测性

- 结构化运单轨迹：线路、承运商、服务等级、SLA、异常码和 5 节点时间线。
- 运单详情页：`/shipment-detail`，展示查询结果、轨迹和异常提示。
- 运营指标看板：运单状态、承运商履约、异常分布和人工转接率。
- API 层端到端验收集：覆盖查件、报价、清关、禁限寄、异常、工单和权限边界。

## 后续可选：继续做出项目特色

1. 接入真实承运商接口和正式用户/角色权限系统。
2. 在有稳定 GPU/HF 环境后，基于本次对比结果进行 Transformer 微调并记录训练前后指标。
3. 将知识命中率、线路趋势图和工单状态流转接入管理员看板。

## 每次开发的验收标准

- 代码静态检查通过。
- 知识库能检索到新增资料，并返回引用。
- 具体运单查询必须经过用户身份校验。
- 不把密钥、真实个人信息或内部服务地址提交到 Git。
- README 只描述本项目，不保留外部课程、配套源码或原始项目归属信息。
